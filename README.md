# Content Brain

Your personal content creation app for capturing ideas and creating storytelling videos.

## Features

- 💡 **Idea Storage**: Keep all your creative thoughts in one place
- ✍️ **AI Content Generation**: Automatically generate written content from your ideas
- 🎬 **Video Script Generator**: Create platform-specific scripts for TikTok, Instagram, YouTube, and LinkedIn
- 📊 **Storyboard Creator**: Visualize your video with timeline and scene breakdowns
- 🎯 **Multi-Platform Support**: Optimized for TikTok, Instagram Reels, YouTube, and LinkedIn
- 🌟 **Warm & Personal**: Conversational tone with nuggets of insight in every video

## Getting Started

1. Clone this repository
2. Copy `.env.example` to `.env` and add your Anthropic API key
3. Install dependencies: `npm install`
4. Run the app: `npm run dev`
5. Open http://localhost:5173 in your browser

## How to Use

1. **Capture Ideas**: Click "New Idea" to save your creative thoughts
2. **Generate Content**: Select an idea and click "Generate Content" to create written content
3. **Create Video Scripts**: Choose a platform and generate a storytelling video script
4. **View Storyboard**: See your video timeline with scene breakdowns, voiceover notes, and camera directions

## Platform Guidelines

- **TikTok**: 5-9s micro-content or 60s+ storytelling, trending sounds, bold hooks
- **Instagram Reels**: 15-60s visual stories with transformations
- **YouTube**: 60s-10min+ in-depth educational content
- **LinkedIn**: 30-90s professional, value-driven content

## Tech Stack

- Frontend: React + Vite + Tailwind CSS
- Backend: Node.js + Express
- Database: SQLite
- AI: Anthropic Claude API
